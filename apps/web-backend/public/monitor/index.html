Architecture

A device-monitoring platform split into three independently deployable pieces: a backend service cluster, a web dashboard, and a companion desktop app.

Backend

NestJS API, dedicated WebSocket service, and ingestion/cron workers.

  • REST API (Swagger docs)
  • WebSocket service for live device status
  • Ingestion worker + cron worker (Redis, Postgres, MongoDB, ClickHouse)
  • Deployed as Docker images on AWS ECS, built and pushed via GitHub Actions with OIDC (no long-lived AWS keys)

Frontend dashboard

React + Vite web app.

  • Pair a device via a QR code
  • Live device list and status
  • Per-device real-time monitor view

Desktop app

Electron app reporting local system metrics (CPU, memory, disk, uptime).

  • Packaged for Windows (NSIS installer) and Linux (AppImage)
  • Built and released via a tag-triggered GitHub Actions pipeline
  • Published to GitHub Releases and mirrored to S3

Install the desktop app

No app store — direct-download installers only. macOS isn't packaged yet.

Windows

  1. Download System Monitor-Setup-win.exe
  2. Run the installer and follow the setup wizard.
  3. The installer isn't code-signed yet, so SmartScreen may warn about an unknown publisher — choose More info → Run anyway to continue.
Download for Windows

Linux

  1. Download System Monitor-Setup-linux.AppImage
  2. Make it executable and run it:
chmod +x "System Monitor-Setup-linux.AppImage"
./"System Monitor-Setup-linux.AppImage"
Download for Linux

Connect the app

The desktop app currently runs standalone and reports metrics for the local machine only — it doesn't connect to a dashboard account yet. Once device pairing is available, the steps to link an installed desktop app to a device on the dashboard will be documented here.
